# LongHorizonOS v0.1.0 — Release Notes

This is the first capability-bearing release of LongHorizonOS: a frozen Core V1
architecture, a public (experimental) SDK, model and tooling integrations, an
observability + CLI surface, a self-contained crash-recovery demo, and an
independent semantic-repair benchmark. It is an **RC-ready** candidate: the code
and tooling are release-ready, but a public release is gated on a LICENSE, which
is a decision owned by the project lead and is therefore a documented blocker
(see `artifacts/oss_productization_e6/LICENSE-BLOCKER.md`).

## Highlights

**Core V1 is frozen.** The deterministic execution plane (Kernel: Process /
Action / Journal / Capability / Lease / Artifact FS / Namespace / Context VM) and
the evidence-backed semantic control plane (Verified Progress Graph, Multi-Agent
Scheduler, Causal Invalidation / Local Repair) are audited, freeze-recorded, and
tagged `longhorizonos-core-v1`. The canonical contract is
`docs/architecture/LONGHORIZONOS-CORE-V1.md`; the freeze record is
`docs/architecture/CORE-V1-FREEZE.md`.

**Public SDK (experimental, E1).** A thin, authority-preserving facade over Core:
`AgentOS`, `Agent`, `Goal`, `Task`, `RunResult`, `RepairOutcome`,
`StatusSnapshot`, typed errors, and verifiers (`scripted_executor`,
`callback_verifier`, `command_verifier`). The SDK never sets VERIFIED on its own
and never fabricates ownership — validity is always derived by Core VPG.

**Model and tool integrations (E2), fail-closed by default.** An OpenAI-compatible
transport with a pluggable offline `FakeTransport`, and shell / workspace / git
tools. Verification is fail-closed: a Task with no verifier stays UNVERIFIED
rather than being silently trusted.

**Observability + Core-native CLI (E3).** `StatusView`/`TaskView`, a `save_run`
manifest format, and a `lhos` CLI (`status` / `inspect` / `graph` / `demo`,
`--json`). The legacy spec-20 CLI remains reachable via `lhos legacy`.

**Crash-recovery demo with local repair (E4).** `lhos demo recovery-repair`
replays a genuine Worker `SIGKILL`, recovery of execution ownership, a real
ArtifactVersion change invalidation, preservation of unaffected VERIFIED work,
and a minimal Repair Frontier that re-closes the Goal with new exact-version
evidence.

**Semantic-repair benchmark (E5).** An independent correctness oracle measures
progress preservation. Headline: when **24%** of a verified 50-task graph is
causally affected, LongHorizonOS recomputes **12** tasks and preserves **38**; a
full restart recomputes **50** — preservation ratio **0.76**, recomputation
**0.24** — with `under_invalidation = 0` and `over_invalidation = 0` across a
quick sweep.

## Known limitations

- The SDK is **v0.x experimental, not SDK 1.0**; its surface may change without
  backward-compatibility guarantees (see `docs/sdk/PUBLIC-API.md`).
- The Core's atomic patch commit is a single-patch model with a size cap
  (~500 ops), so very large synthetic graphs are benchmarked up to N=100 in one
  patch. This is an SDK/single-patch limitation, not a Core defect.
- A **LICENSE file is not yet present**. The package is source-available; a
  public release distribution is blocked pending the license decision:
  `artifacts/oss_productization_e6/LICENSE-BLOCKER.md`.
